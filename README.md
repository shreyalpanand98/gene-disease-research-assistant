
# Gene–Disease Research Assistant

A research assistant built as part of the CMU Agentic AI Capstone Project.

## Overview

This project aims to help researchers explore relationships between
genes and diseases using public biomedical databases.

## Current Features

- NCBI Gene lookup
- Exact gene symbol matching
- PubMed literature search
- Article metadata and abstract retrieval
- MCP-based tool integration

## Technology Stack

- Python
- Model Context Protocol (MCP)
- NCBI E-utilities
- PubMed

## Project Status

Under active development.

## Data Sources

This project uses publicly available biomedical research data.

## Disclaimer

This system is for research and educational use only.
It does not provide medical diagnosis or treatment advice.
